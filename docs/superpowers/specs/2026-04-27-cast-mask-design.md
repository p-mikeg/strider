# Selective Cast Walk-Through (`CastMask`) — Design

## Goal

Extend the `pattern` crate's `Matcher::ignore_casts()` builder so callers
can choose **which** cast `NodeKind` variants the matcher walks through
transparently, while keeping the existing "ignore all casts" behaviour
exactly as it is today.

## Motivation

`Matcher::ignore_casts()` is currently a single boolean toggle that
makes the matcher walk past any of seven value-passthrough cast
NodeKinds:

```
Extend(ExtendOp), Truncate, CastToInt, CastToFloat, CastToBool,
IntBitsToFloat, FloatBitsToInt
```

Some patterns want finer control:
* Skip width casts (`Extend`/`Truncate`) but not `IntBitsToFloat`.
* Skip only `ZeroExtend` (preserve sign-extension semantics).
* Skip everything (current behaviour).

The all-or-nothing toggle conflates "structural noise" with operations
that change semantic value class. A bitset selector lets callers pick.

## API

### New: `pattern::CastMask`

A bitset using the `bitflags` crate, gated by individual cast kinds.

```rust
use bitflags::bitflags;

bitflags! {
    /// Bitset selecting which value-passthrough cast NodeKinds the
    /// matcher walks through transparently.
    #[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Hash)]
    pub struct CastMask: u32 {
        const ZERO_EXTEND       = 1 << 0;
        const SIGN_EXTEND       = 1 << 1;
        const TRUNCATE          = 1 << 2;
        const CAST_TO_INT       = 1 << 3;
        const CAST_TO_FLOAT     = 1 << 4;
        const CAST_TO_BOOL      = 1 << 5;
        const INT_BITS_TO_FLOAT = 1 << 6;
        const FLOAT_BITS_TO_INT = 1 << 7;

        /// Both extension flavours (zero + sign).
        const EXTEND = Self::ZERO_EXTEND.bits() | Self::SIGN_EXTEND.bits();
    }
}
```

`CastMask::all()` (auto-generated by `bitflags`) is the union of every
flag and corresponds to the previous `ignore_casts()` toggle.

### Crate-private helper

```rust
pub(crate) const fn cast_mask_of(kind: &NodeKind) -> CastMask
```

Maps a `NodeKind` to the single-bit `CastMask` for that cast, or
`CastMask::empty()` for non-cast kinds. The match must be exhaustive
(no `_` arm), matching the existing `is_cast_kind` discipline so a new
NodeKind cast variant is a compile error rather than a silent miss.

### `MatcherOptions` change

```rust
pub struct MatcherOptions {
    /// Mask of cast kinds to walk through.  Default `CastMask::empty()`
    /// (strict).  `Matcher::ignore_casts()` sets this to
    /// `CastMask::all()` for source compatibility with the previous
    /// boolean toggle.
    pub ignore_cast_mask: CastMask,
    pub ignore_control_states: bool,
}
```

The previous `pub ignore_casts: bool` field is removed; consumers
inside the crate read `ignore_cast_mask` directly.

### `Matcher` builder

```rust
impl<'g> Matcher<'g> {
    /// Walk through every value-passthrough cast — equivalent to
    /// `.ignore_casts_mask(CastMask::all())` and to the previous
    /// boolean `ignore_casts()` behaviour.
    #[must_use]
    pub fn ignore_casts(mut self) -> Self {
        self.options.ignore_cast_mask = CastMask::all();
        self
    }

    /// Walk through only the casts present in `mask`.  Multiple calls
    /// union: `m.ignore_casts_mask(CastMask::TRUNCATE)
    ///         .ignore_casts_mask(CastMask::EXTEND)` → both bits set.
    #[must_use]
    pub fn ignore_casts_mask(mut self, mask: CastMask) -> Self {
        self.options.ignore_cast_mask |= mask;
        self
    }
}
```

### Match-site change

In `matcher::mod.rs::match_one_with_walk_through`:

```rust
// before:
//   if self.options.ignore_casts && try_walk_through_cast(...) { ... }
// after:
if !self.options.ignore_cast_mask.is_empty()
    && walk_through::try_walk_through_cast(&self.ctx(), out, pat, b)
{ return true; }
```

`try_walk_through_cast` itself filters per-bit using
`self.options.ignore_cast_mask.contains(cast_mask_of(kind))`, so the
outer `is_empty()` guard is just a fast-path skip when the mask is
empty.

### `walk_through.rs` changes

* Replace `is_cast_kind(kind: &NodeKind) -> bool` with
  `cast_mask_of(kind: &NodeKind) -> CastMask` (defined in `cast_mask`
  module, re-exported as `pub(crate)`).
* `try_walk_through_cast` consults the mask:
  ```rust
  let bit = cast_mask_of(ctx.graph.graph.node_kind(producer));
  if !ctx.matcher.options.ignore_cast_mask.contains(bit) {
      return false;
  }
  ```

## Backward compatibility

* `Matcher::ignore_casts()` keeps the same signature and same observable
  behaviour (walks through every cast). Existing call sites in
  `crates/opt`, `crates/analyzer/tests`, etc. continue to work
  unchanged.
* `MatcherOptions::ignore_casts: bool` is removed and replaced with
  `ignore_cast_mask: CastMask`. The field is `pub`; any external
  reader of the field would break, but a workspace-wide grep shows no
  reader outside the matcher module itself.

## Tests

### Basic — `CastMask` semantics
File: `crates/pattern/src/matcher/cast_mask/tests.rs`.

* All 8 individual flags use distinct, non-overlapping bits.
* `EXTEND == ZERO_EXTEND | SIGN_EXTEND`.
* `CastMask::all().contains(X)` for every individual `X`.
* `CastMask::empty().is_empty()`; `CastMask::all().is_empty() == false`.
* Bit operators (`|`, `&`, `!`) round-trip via `bitflags`-generated
  impls.
* `cast_mask_of(NodeKind::Extend(ExtendOp::ZeroExtend)) == ZERO_EXTEND`,
  same for each cast variant.
* `cast_mask_of(NodeKind::IntConst(0)) == CastMask::empty()` and a
  representative selection of other non-cast kinds.

### Basic — `Matcher` builder API
File: extends the existing matcher unit tests in
`crates/pattern/src/matcher/mod.rs::tests` (or a new
`crates/pattern/src/matcher/options_tests.rs`).

* Default options: `ignore_cast_mask.is_empty()`.
* `Matcher::new(g).ignore_casts().options_for_test().ignore_cast_mask
  == CastMask::all()`.
* `ignore_casts_mask(CastMask::TRUNCATE)` sets just `TRUNCATE`.
* Two `ignore_casts_mask` calls union (`TRUNCATE | EXTEND`).
* `ignore_casts()` after `ignore_casts_mask(TRUNCATE)` widens to `all`.

### Comprehensive — walk-through behaviour
File: new `crates/pattern/src/matcher/cast_mask_walk_tests.rs`, using
`graphmock` (already a workspace dependency) to build minimal IR
fixtures.

For each fixture, run a representative pattern and assert match-count
== expected:

| Fixture | Mask | Expected |
|---|---|---|
| `Add(Truncate(x), c)` | `empty` | 0 matches |
| `Add(Truncate(x), c)` | `TRUNCATE` | 1 |
| `Add(Truncate(x), c)` | `EXTEND` | 0 |
| `Add(Truncate(x), c)` | `all()` | 1 |
| `Add(Extend(ZeroExtend, x), c)` | `ZERO_EXTEND` | 1 |
| `Add(Extend(ZeroExtend, x), c)` | `SIGN_EXTEND` | 0 |
| `Add(Extend(ZeroExtend, x), c)` | `EXTEND` | 1 |
| `Add(Extend(SignExtend, x), c)` | `SIGN_EXTEND` | 1 |
| `Add(Extend(SignExtend, x), c)` | `ZERO_EXTEND` | 0 |
| `Add(Extend(SignExtend, x), c)` | `EXTEND` | 1 |
| `Add(Truncate(Extend(ZeroExtend, x)), c)` | `TRUNCATE` only | 0 |
| `Add(Truncate(Extend(ZeroExtend, x)), c)` | `ZERO_EXTEND` only | 0 |
| `Add(Truncate(Extend(ZeroExtend, x)), c)` | `TRUNCATE \| ZERO_EXTEND` | 1 |

Pattern in every row: `add(initial_var(x_vn), int_const(_))` (the
canonical "the matcher would normally fail because of an intervening
cast" shape that motivated the original `ignore_casts()`).

### Comprehensive — non-regression
* `cargo test --workspace --no-fail-fast` — no regression in any
  existing `ignore_casts()` consumer (notably the BUG-19 regression
  guard in `crates/analyzer/tests/patterns.rs`).
* `cargo clippy --workspace --all-targets` clean.

## Out of scope

* Splitting `IntBitsToFloat` / `FloatBitsToInt` further by source/dest
  width — these are atomic kinds in the IR with no sub-variants today.
* Selective `ControlState` walk-through (separate flag, separate
  feature).
* Compile-time type-level masks — the runtime bitset is sufficient.
