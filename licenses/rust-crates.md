# Licences of the Rust crates linked into the Python extension

Strider's Python extension module statically links the crates below. Their
licence texts follow, deduplicated: a text shared by several crates is printed
once, under the list of the crates that ship it.

Regenerate from `cargo tree -p strider-py -e normal --target
x86_64-unknown-linux-gnu`, the crates a strider-py build links (a
workspace-wide `cargo metadata` resolve unifies features and lists more),
concatenating each crate's `LICENSE*`, `COPYING` and `UNLICENSE` files.
